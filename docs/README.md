# dds98 documentation

| file | what it is |
|---|---|
| `MATCHING.md` | **the ledger**: every verified function, its source file, flags, size and status (MATCH / RELOCS / ASM / PENDING). This is the single source of truth; `tools/verify.py` rebuilds every row from source |
| `STATUS.md` | generated by `tools/report.py`: ledger totals, coverage, and the pool breakdown |
| `BLOCKED.md` | generated by `tools/classify.py`: every unmatched unit bucketed into one of 20 compiler-habit classes, with the byte test used |
| `WALLS.md` | the same blockers written out as prose, with a verified example unit for each and what would unblock them |
| `CONVENTIONS.md` | source-level rules learned from matching: calling conventions, push order, register staging, frame rules, and the traps that look like bugs |
| `GAP.md` | what is known about the toolchain - which compilers run, which do not, and what has been ruled out |

## Working on it

    python build.py src/calib/<file>.c --flags "/G1 /AM /Gs /Os"       # compile
    python tools/match.py <seg:off> <SYMBOL> --obj build/<file>.OBJ --size <n>
    python tools/verify.py                                            # rebuild every row
    python tools/verify.py --fast                                     # sample check
    python tools/checkled.py                                          # ledger consistency

Screening helpers:

| tool | use |
|---|---|
| `tools/nextup.py` | rank unmatched units by likely payoff |
| `tools/cutwin.py` | units whose `units.csv` window cuts the function short |
| `tools/dis.py` | annotate a slice: offsets, bytes, jump targets, call forms |
| `tools/reuse.py` | find units byte-identical to a verified source |
| `tools/probe.py` | sweep every calibration source against every window in the image |
| `tools/coverage.py` | coverage arithmetic |

## Reading a new candidate

1. `tools/dis.py <va> <len>` first - two of this project's longest-lived wrong
   conclusions came from hand-decoding byte offsets.
2. Check the walls (`WALLS.md`). If the unit carries a wall, it is not matchable with
   MSC 7 and the only useful output is a better description of the wall.
3. Check the size: `units.csv` is sometimes short (`cutwin.py`) and sometimes includes a
   trailing padding byte. The object symbol's length is authoritative.
4. If the prologue is only `55 8B EC` plus a register save, assume **no locals**.
5. Compile with `/G0` when the unit has locals (classic frame) and `/G1` when it has
   none and uses 80186 encodings.
