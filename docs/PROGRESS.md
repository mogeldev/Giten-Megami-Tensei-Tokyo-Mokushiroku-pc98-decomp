# PROGRESS

The round-by-round record, compacted: this file is the **index** (one line per round, newest
first) and the summary of what each phase established. The full notes - every measurement,
every failed transcription, every correction - are in **`history/progress-full.md`**, preserved
verbatim, and each line below has a matching heading there.

## The five phases

**1-100 — bootstrap.** The inventory (`ground_truth/units.csv`), a real 8086 decoder
(`tools/dis.py`), the match harness (`tools/match.py`) and the first walls. This phase
established the method: read the bytes with a tool, transcribe, match, and record why a miss
happened rather than moving on.

**101-180 — rules.** The prototype decides widening; register locals reverse; `/Ox` reuse; the
`8A E0`/`8A C4` distinction; `void` versus "returns 0". Each rule came from a one-byte miss and
each then paid for itself several times.

**181-215 — walls measured.** The doubling class closed by experiment (twelve compilations,
always `shl`), the pad byte closed (six statement shapes, no `90` in a body), BX never a C
variable, the register cache counted, the prologue push order fixed.

**216-244 — declarations.** The pascal offset table, the `char` parameter slot, and the
near/far tell (`ret n` with the first parameter at `[bp+04]` is near) - which turned two
transcriptions that had failed rounds earlier into rows unchanged. Also the `ENTER` pool, where
MSC makes the same frame choice as the original.

**245-256 — consolidation.** Derived documents regenerated and kept in step with the ledger, a
handoff guide, a publication audit, and eleven full verification sweeps.
